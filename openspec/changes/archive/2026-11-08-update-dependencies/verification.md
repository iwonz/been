# Проверка обновления зависимостей

Дата: 2026-11-08. Среда: macOS arm64, Node.js 24.14.0, Yarn Classic 1.22.22.

## Версии и установка

- React / React DOM 19.3.1, Vite 8.3.6, TypeScript 7.0.2, Biome 2.6.6, Knip 6.44.2; версии проверены по npm registry.
- Обновлены совместимые типы и SWC-плагин; gh-pages 6.3.0 уже был актуальным.
- ESLint, Prettier и их плагины удалены из package.json и yarn.lock. Принудительных resolutions нет.
- Чистая установка копий package.json и yarn.lock в пустой временной папке: `yarn install --frozen-lockfile --offline --non-interactive` — успешно. Lockfile побайтово не изменился; временная папка удалена.
- Сохранены `/been/` и прежние цели сборки: es2020, Edge 88, Firefox 78, Chrome 87, Safari 14. Это настройка трансформации, а не результат тестирования всех этих браузеров.

## Автоматические проверки

- `yarn verify` — успешно: Biome проверил 26 файлов без замечаний, Knip не нашел неиспользуемых частей, TypeScript и Vite собрали production.
- `openspec validate --all --strict --no-interactive` — 4/4 до архивации.
- `git diff --check` — успешно; данные посещений и JSON границ не изменены.
- Временный файл с `debugger` и неиспользуемым экспортом дал ненулевые коды Biome и Knip. Отдельная временная React-функция с условным hook и пропущенной зависимостью effect вызвала `useHookAtTopLevel` и `useExhaustiveDependencies`. Контрольные файлы удалены.
- Самопроверка bootstrap: текущий src/main.tsx преобразован установленным SWC в CommonJS и выполнен с подменами DOM/React/addScript. `assert.rejects` подтвердил ошибку `Root element #root is missing` без root; с root подтверждены render и доступность window.downloadBorders.
- `yarn audit --json --registry https://registry.npmjs.org` — код 0, все уровни уязвимостей равны 0, 203 зависимости в отчете. До обновления: low 9, moderate 34, high 60, critical 0 (счетчики отчета включают пути зависимостей).

## Браузерная проверка

Playwright CLI / Chromium, dev на `http://127.0.0.1:5173/been/` и production preview на `http://127.0.0.1:4173/been/`:

- Карта, тайлы, маркеры и окрашенные территории отображаются; countries.json и regions.json отвечают HTTP 200 в обоих режимах.
- Маркер события в Карелии открывает балун «События в этом месте» со ссылкой «Гулял»; в preview проверен адрес `https://vk.com/narrative-222060304_98582` без перехода на внешний сайт.
- Hover показывает подсказки и обводку регионов; при уходе указателя выделение снимается.
- Статистика: 14 стран, 77 населенных пунктов, 21 из 89 регионов России, 18 аэропортов.
- Проверены повторная загрузка и viewport 390×844: одна карта, window.downloadBorders остается функцией, ширина документа равна 390 без горизонтального переполнения. Production не генерирует pageerror.
- Скриншоты визуально проверены; временные артефакты находятся в `/tmp/been-browser/` и не входят в репозиторий.

## Ограничения

- Yandex Maps сообщает `Invalid API key`; URL подключения API по-прежнему не содержит ключ. В среде проверки не проходят запросы телеметрии к log.api-maps.yandex.ru; карта, тайлы, границы и балун работают. Подключение API этим изменением не менялось.
- Yarn Classic на Node.js 24 выводит deprecation warning про url.parse. SWC-плагин Vite рекомендует переход на plugin-react для производительности; сборка и проверки успешны. Смена пакетного менеджера и сборочного плагина не входила в задачу.
- Нулевой audit относится к известным advisory для этого lockfile на дату проверки; он не является гарантией отсутствия неизвестных уязвимостей. Полный аудит прикладного кода, другие браузеры и публикация сайта не выполнялись.
