## Context

Ветка `chore/update-dependencies` создана от чистой `main`, содержащей актуальную `origin/main`. Мотивация — в proposal.md. Проект использует Yarn Classic, статический React и императивную карту; внешних серверных зависимостей нет.

## Goals / Non-Goals

**Goals:** совместимый современный набор зависимостей, рабочие Biome и Knip, воспроизводимая установка, нулевой отчет известных уязвимостей на момент проверки и сохранение поведения карты.

**Non-Goals:** смена пакетного менеджера, переработка карты, изменение данных посещений, обновление глобальных инструментов машины или публикация сайта.

## Decisions

- Использовать стабильные версии из npm registry: React 19.3.1, Vite 8.3.6, TypeScript 7.0.2, Biome 2.6.6, Knip 6.44.2 и совместимые типы/плагины. Удаление typescript-eslint снимает его ограничение на TypeScript 6; Knip 6 использует Oxc и не требует старого TypeScript API.
- Сохранить Yarn Classic и обновить весь lockfile в допустимых диапазонах. Принудительные resolutions добавлять только при доказанной необходимости и совместимости исправления.
- Biome отвечает за lint, форматирование и импорты; Knip — за неиспользуемые части. `yarn lint` станет проверкой без записи, исправления выполняются отдельной командой. Не отключать целые группы проверок ради зеленого результата.
- Сохранить отступ в два пробела, одинарные кавычки JS/TS, точки с запятой и ширину 100. Большие JSON границ исключить из форматирования. Для нетипизированного Yandex API сохранить существующее разрешение `any`.
- Явно сохранить build target Vite 6 (`es2020`, Edge 88, Firefox 78, Chrome 87, Safari 14), чтобы обновление сборщика не уменьшило совместимость браузеров по умолчанию. Документировать современный Node.js для инструментов.
- Не добавлять постоянный браузерный тестовый фреймворк: выполнить smoke-проверку реальной карты в dev и production preview, плюс временные проверки конфигурации и срабатывания Knip.

## Risks / Trade-offs

- Новые версии компилятора и сборщика могут менять обработку модулей → проверить TypeScript build, загрузку `/been/`, JSON границ, маркеры, балун, hover и отсутствие ошибок приложения в браузере.
- Biome может форматировать иначе → просмотреть diff, не менять данные и смысл кода.
- Knip может ошибочно считать браузерный экспорт или ambient declarations неиспользуемыми → сохранить `window.downloadBorders`, уточнять точки входа только при подтвержденной необходимости.
- Отсутствие advisory не гарантирует отсутствие неизвестных уязвимостей → отчет ограничен результатом аудита конкретного lockfile на дату выполнения.

## Migration Plan

Обновить зависимости и конфигурации, выполнить проверки каждой логической части, зафиксировать проверенную реализацию, затем архивировать change, слить в `main` и повторить проверки. При несовместимости исправлять ее в рабочей ветке; откат обновления возможен отдельным revert-коммитом.
