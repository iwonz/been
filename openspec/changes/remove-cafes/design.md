## Context

Причина и объем описаны в proposal.md. Маркеры создаются из общего массива; `CAFE` — последний элемент числового enum и не имеет собственной ветки выбора иконки. Помимо девяти записей отдельного списка, в местах есть два явно названных кафе и одна кофейня.

## Goals / Non-Goals

**Goals:** удалить данные и тип без скрытых маркеров и без изменения остальных локаций.

**Non-Goals:** фильтр видимости кафе, перенос их в места, переработка карты, обновление API-ключа или зависимостей.

## Decisions

- Физически удалить список и ссылки на него, последний элемент enum и три записи заведений в местах. Фильтрация при отрисовке оставила бы ненужную сущность в данных.
- Сохранить общие иконки и счетчики: они используются оставшимися типами. Числовые значения четырех типов после удаления последнего элемента enum сохраняются.
- Проверить данные сравнением с чистой main: результат равен прежнему массиву без двенадцати удаляемых точек; остальные поля и порядок совпадают. Дополнительно проверить карту и число маркеров в браузере.

## Risks / Trade-offs

- Удаление лишних мест → удалять только записи отдельного списка и три явно обозначенных заведения; остальные места сохранить.
- Потеря приостановленных правок → они сохранены в именованном stash и ветке настройки ключа; не применять их в эту задачу.
- Старое предупреждение API-ключа на main → при проверке отличать его от ошибок отрисовки; задача активации ключа остается приостановленной.
