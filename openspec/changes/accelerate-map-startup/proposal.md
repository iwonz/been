## Why

Интерфейс ожидает внешний API, а загрузка раскраски требует около 10 МБ gzip и создания 349 полигонов с 642 тысячами точек. Нужно раньше показывать карту и уменьшить сетевые и синхронные затраты без смены картографического движка.

## What Changes

- Ранняя загрузка API параллельно с приложением и немедленное отображение контейнера и статистики.
- Проверка ограниченного набора модулей API с сохранением контролов, подсказок, балунов и команды обновления границ.
- Округление координат границ до пяти знаков при сохранении всех точек и качества исходных данных 3.
- Независимая загрузка стран и регионов, постепенное добавление объектов с возможностью отрисовки между порциями.
- Сообщения об ошибке API или отдельных слоев; доступные части карты продолжают работать.
- Воспроизводимые проверки геометрии, порядка загрузки, взаимодействий и сравнение production-загрузки до/после.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `travel-map`: раннее отображение, независимость слоев, отзывчивость загрузки и компактный экспорт границ.

## Impact

Затронуты `index.html`, `src/main.tsx`, `src/components/Map/`, конфигурация загрузки API, типы геометрии, утилиты загрузки/экспорта границ, `public/countries.json`, `public/regions.json`, документация и небольшие проверки без нового тестового фреймворка. Сохраняются `/been/`, все локации, статистика, цвета, группировки и защита от повторной инициализации. Упрощение геометрии по масштабу, загрузка по видимой области и смена движка не входят в этап.
