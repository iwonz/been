# Проверки производительности

Исходная сборка сохранена отдельно для повторного сравнения. Chrome, production Vite preview, локальная сеть, реальный Yandex Maps API. В первом открытии до изменений: API запрошен на 68,5 мс, ответ получен на 613,7 мс; FCP 676 мс; запросы границ начались на 1429,6 мс, страны получены на 1829,4 мс, регионы на 1686,5 мс. Это наблюдение одной загрузки, не гарантия скорости внешнего API.

Повторное исходное открытие с наблюдателем: создание карты 379 мс, все маркеры 392 мс, все полигоны 2559 мс, максимальная длинная задача 1711 мс. Одна карта. Только округление: 343 / 356 / 2373 мс, длинная задача 1747 мс — уменьшение передачи само по себе не решает блокировку отрисовки.

После округления проверены все 641772 точки: порядок и количество точек/контуров, коды территорий и метаданные сохранены; максимальная погрешность одной координаты 0,000005°. Node gzip: страны 6317178 → 2903991 байт, регионы 3689907 → 1652153 байт (в сумме −54,5%). Исходный объем JSON 24914383 → 13114056 байт. Визуально проверено отображение всех слоев на начальном масштабе.

`yarn verify` включает встроенные Node-тесты округления и структуры данных, Biome, Knip, TypeScript и Vite. Зависимости не добавлялись.

Для каждого открытия до навигации установлен PerformanceObserver longtask и наблюдатель requestAnimationFrame. Прозрачная обертка конструктора Yandex Map сохраняет ссылку только в тестовой странице; готовность объектов определяется по фактическим коллекциям (171 маркер, 232 страны, 117 регионов). Эти времена не означают загрузку всех тайлов: внешний API и тайлы зависят от сети. В каждой загрузке создана одна карта. API запрашивается один раз, preload повторно используется загрузчиком.

## Проверки поведения

- HTTP 503 для стран: сообщение об ошибке, 117 регионов и 171 маркер доступны.
- HTTP 503 для регионов: сообщение об ошибке, 232 страны и 171 маркер доступны.
- Блокировка API: сообщение об ошибке и статистика, карта не дублируется.
- Искусственная задержка каждого файла: другой слой появляется до снятия задержки; региональные подсказки содержат название страны.
- Задержка API: статистика видна до появления `ymaps`.
- Dev StrictMode: одна карта, коллекции 232 / 117 / 171, без дубликатов.
- Проверены hover страны, вся группа RU со специальными кодами, сброс обводки, балун маркера «Пекин» со ссылкой «Сюжет» и наличие линейки.
- Фоновые сетевые ошибки `log.api-maps.yandex.ru` воспроизводятся и в исходной сборке; ошибок JavaScript приложения в успешной загрузке нет.
- Fullscreen включается и выключается, линейка активируется; граница Москвы визуально сопоставлена до/после при центре `[55.14417, 37.05136]` и масштабе 16.
- Интерфейс поиска принимает запрос «Казань», но реальный сервис отвечает «Сервер не смог обработать запрос» и до, и после изменений. Успешный ответ внешнего поиска в этой сессии не проверен.
- Реальный экспорт границ и до, и после изменений отклоняется внутри API Яндекса с `BASE_URL is not set`. Это существующее ограничение источника, не следствие ограничения модулей. После реальной загрузки модуля `borders` проверен контролируемый успешный ответ: запросы `001`, `RU`, `BY`, `UA` с `lang: ru`, `quality: 3`, скачивания `countries.json` и `regions.json`, округление в обоих файлах до `[1.12346, 2.23457]`. Успешное скачивание свежих реальных границ не подтверждено.
