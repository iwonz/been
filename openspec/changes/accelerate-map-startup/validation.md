# Проверки производительности

Исходная сборка сохранена отдельно для повторного сравнения. Chrome, production Vite preview, локальная сеть, реальный Yandex Maps API. В первом открытии до изменений: API запрошен на 68,5 мс, ответ получен на 613,7 мс; FCP 676 мс; запросы границ начались на 1429,6 мс, страны получены на 1829,4 мс, регионы на 1686,5 мс. Это наблюдение одной загрузки, не гарантия скорости внешнего API.

Повторное исходное открытие с наблюдателем: создание карты 379 мс, все маркеры 392 мс, все полигоны 2559 мс, максимальная длинная задача 1711 мс. Одна карта. Только округление: 343 / 356 / 2373 мс, длинная задача 1747 мс — уменьшение передачи само по себе не решает блокировку отрисовки.

После округления проверены все 641772 точки: порядок и количество точек/контуров, коды территорий и метаданные сохранены; максимальная погрешность одной координаты 0,000005°. Node gzip: страны 6317178 → 2903991 байт, регионы 3689907 → 1652153 байт (в сумме −54,5%). Исходный объем JSON 24914383 → 13114056 байт. Визуально проверено отображение всех слоев на начальном масштабе.
