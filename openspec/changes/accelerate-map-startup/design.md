## Context

См. `proposal.md`. Внешний API сейчас запрашивается после выполнения основного JS. Полный набор границ содержит 641772 точки; файлы уже обслуживаются GitHub Pages с gzip. Региональные подсказки зависят от названий трех стран из большого файла стран.

## Goals / Non-Goals

**Goals:** сократить критическую цепочку старта и объем данных, сохранить все существующие взаимодействия, проверить поведение при задержках и сбоях.

**Non-Goals:** новый движок, backend, кластеризация, Service Worker, Worker, изменение количества точек и уровни детализации.

## Decisions

- Предзагрузка скрипта из HTML и `preconnect`; существующий загрузчик остается владельцем Promise готовности. React рендерится немедленно, эффект ожидает готовности API. URL preload и реального запроса проверяются на совпадение. Ограниченный набор модулей принимается только после браузерной проверки; `borders` загружается по запросу команды экспорта.
- Сохранить singleton карты и разделяемый Promise инициализации, чтобы StrictMode не дублировал карту или слои. Ошибки отображать доступным сообщением, не удаляя карту.
- Округлять только координаты до пяти знаков общей небольшой функцией, используемой экспортом и одноразовым преобразованием существующих данных. Не округлять метаданные и не упрощать контуры. Локальный расчет дает примерно 4,6 МБ gzip вместо 10,1 МБ.
- Названия RU, UA и BY хранить рядом с конфигурацией стран с регионами. Это позволяет загружать и отрисовывать оба слоя независимо, включая специальные группировки.
- Добавлять слои небольшими порциями с передачей управления через браузерные кадры/задачи; сохранить явный порядок слоев независимо от завершения запросов. Обработку HTTP-ошибок и проверку структуры вынести в общий загрузчик. Ошибки слоев обрабатывать раздельно.
- В тестах использовать встроенный Node test/assert и существующий TypeScript/SWC, без новой зависимости. Браузерные замеры выполняются на production preview и сохраняются вместе с условиями измерения; внешнюю сеть не выдавать за контролируемый benchmark.

## Risks / Trade-offs

- Сдвиг координат при округлении → проверить максимальную погрешность, идентичность метаданных/числа точек и внешний вид на масштабе 16.
- Ограничение модулей API может лишить карту дополнений → проверить контролы, hover, балуны и загрузку `borders`.
- Независимая загрузка меняет порядок появления → зарезервировать коллекции заранее; проверить медленный и недоступный слой в обе стороны.
- Число вершин не уменьшается, JSON parsing и один крупный полигон могут оставаться длинными задачами → измерить остаточную стоимость; детализация по масштабу остается следующим этапом.

## Migration Plan

Проверить исходную production-сборку, реализовать и проверить логические части отдельными коммитами, выполнить полный verify и строгую валидацию. После браузерной приемки синхронизировать спецификации, архивировать change, локально слить и повторить проверки. Публикация не входит в запрос; откат возможен возвратом коммитов и предыдущих JSON.
